# E-Commerce Superstore Sales Analysis

## Project Overview

This project focuses on analyzing an E-Commerce Superstore dataset using Excel, SQL, and Power BI to uncover business insights related to sales performance, profitability, customer behavior, and regional trends.

The project demonstrates the complete data analysis workflow including:

* Data Cleaning
* Data Analysis
* SQL Querying
* Interactive Dashboard Creation
* Business Insight Generation

---

# Tools & Technologies Used

* Microsoft Excel
* MySQL
* Power BI
* Git & GitHub

---

# Dataset Information

The dataset contains:

* Order Details
* Customer Information
* Product Categories
* Sales & Profit Metrics
* Regional & Market Data
* Shipping Details

Total Records: 50,000+ rows

---

# Data Cleaning Process (Excel)

The raw dataset was cleaned using Excel by performing:

* Removed duplicate records
* Handled missing/null values
* Standardized inconsistent text values
* Fixed incorrect date formats
* Corrected invalid numerical values
* Removed unnecessary spaces and formatting inconsistencies

# Key Business Insights

* Sales peaked during November and December, indicating strong year-end demand.
* Technology category generated the highest sales and profit.
* Phones and Copiers were among the most profitable subcategories.
* Tables subcategory recorded losses despite generating sales.
* APAC market contributed significantly to overall revenue.
* Standard Class was the most frequently used shipping mode.
